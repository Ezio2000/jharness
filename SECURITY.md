# Security Policy

Do not disclose credentials, user data, exploit details, or an unpatched proof of
concept in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/Ezio2000/jharness/security/advisories/new)
when available. Otherwise, open a
[minimal public issue](https://github.com/Ezio2000/jharness/issues/new) containing no
sensitive details and ask the maintainer to establish a private channel. Include the
affected JHarness version, Python and operating-system versions, a minimal reproduction,
and an impact assessment in the private report.

The latest published minor line receives security fixes. JHarness is not an
operating-system sandbox; deployment guidance is in the
[`jharness-tools` README](packages/jharness-tools/README.md).
